# THE LAST CHANCE — Detective Word Mystery

> **Bureau of Criminal Investigation • Confidential Dossier**  
> A sophisticated, handcrafted detective word deduction web game.

---

## 🖋️ Design Philosophy

- **Zero AI Hallmarks**: No electric neons, no dark cyber glows, no generic gradient cards.
- **Human-Crafted Aesthetic**: Warm antique parchment (`#F7F4EB`), deep charcoal ink (`#1F1B18`), British tweed green (`#2D5A43`), aged brass (`#8C6D3F`), and oxblood wax seals (`#8C1D24`).
- **Tactile Micro-Interactions**: Mechanical typewriter keyboard, procedural Web Audio clicks, desk bell dings, and animated rubber ink stamps.

---

## 🕵️‍♂️ Key Features

1. **The Bureau Archives**: Over 40+ curated case dossiers across multiple departments (*The Crime Scene*, *The Syndicate*, *Forensics*, *Court & Law*, and the original *Bureau Archives*).
2. **Interactive Hand-Inked Evidence Visualizer**: Artisan SVG gallows that ink themselves stroke-by-stroke with every strike.
3. **Dual Investigation Modes**:
   - **Classic Deduction**: Methodical 6-strike criminal investigation.
   - **Blitz Interrogation**: 60-second high-stakes countdown with a ticking pocket watch.
4. **Forensic Tools**:
   - **Dossier Inspection**: Read classified crime scene notes and request forensic clues.
   - **Chemical Reagents**: Eliminate 2 incorrect letters from the keyboard in a pinch.
5. **Career Record & Ranks**: Track cases cracked, win streaks, and earn detective ranks (*Chief Inspector*, *Master Sleuth*, *Senior Detective*).
6. **Telegram Dispatch Sharing**: Copy formatted Wordle-style case resolution cards to share with friends.
7. **Custom Sealed Cases**: Type in any secret cipher word to challenge a partner in the room.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## 🌐 Deploy to Vercel (1-Click)

The repository includes a ready-to-use [`vercel.json`](file:///c:/Users/lenovo/Downloads/forgeguard-ai/vercel.json) configuration.

### Option A: Using Vercel CLI
Run the following in your terminal:
```bash
npx vercel
```
Follow the 3 quick prompts (press Enter to accept default settings).

### Option B: Using GitHub & Vercel Dashboard
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your repository. Vercel will automatically detect `vite` and deploy immediately!
